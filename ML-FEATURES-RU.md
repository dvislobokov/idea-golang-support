# ML-функции Go-плагина — что есть, где включается, как проверить

Состояние на 2026-10-08 (0.2.214). Все функции имеют выключатель; по умолчанию включены. Ничего из списка не проверялось
вживую в IDE — сервер без UI; это чеклист для живой проверки.

## Сборки
- Обычная сборка (`./gradlew buildPlugin`): только PSI-функции — маппинг, память принятий, выбор импорта по статистике
  (последний работает, если рядом с плагином есть `ml-models/go/go-imports-e20.cml` или задан каталог моделей).
- ML-сборка (`./gradlew buildPlugin -PmlEnabled=true [-Pml.big=true]` → `idea-golang-support-<версия>-ml.zip`): плюс
  серый текст от нашей сети (31 M, с `-Pml.big` ещё 50 M), ранкер списка (n-gram e14-b + GBDT e19), статистика импортов
  внутри jar. На сервере эта сборка не собирается (Ultimate-классы) — собирать на своей машине.

## Где настройки
- **Settings | Go | Smart Completion** (`GoMlConfigurable`, только ML-сборка): ранкер вкл/выкл, метка « ML» (по умолчанию выкл.),
  серый текст вкл/выкл, пороги уверенности (0.7 общий, 0.5 после точки, 0.25 на пустой строке), большая модель 50 M,
  одиночные закрыватели, подсказки внутри строковых литералов (вкл.) и внутри комментариев (выкл.), вес памяти принятий (0.3),
  строка состояния «модель / ядра / показано / принято».
- **Settings | Go | Editor and Completion** (обычная сборка тоже): «Offer field-to-field copies» (маппинг),
  «Learn from what I accept» + кнопка Reset Memory, «Order imports by corpus statistics».

## Что проверить
1. **Серый текст** (ML-сборка). Открыть Go-файл: в логе `GoMlModels … NativeLib.status` — какие ядра загрузились
   (avx512-vnni / avx2 / neon / scalar). Напечатать `if err != nil {` + Enter — на пустой строке подсказка при уверенности ≥ 0.25;
   `fmt.Errorf("failed to ` — продолжение внутри строки показывается; внутри `// …` — нет. Tab принимает только серый текст, попап
   закрывается. После `x.` порог 0.5. Первая подсказка в только что открытом файле должна прийти быстро (prefill при открытии).
2. **Ранкер** (ML-сборка). Элементы списка без суффикса « ML» (включается в настройках); порядок после точки должен заметно
   отличаться от алфавитного; `rank.cml` в сборке — GBDT e19 (в строке состояния «321 trees»).
3. **Маппинг**. `dto := Dto{⟨⟩}` при переменной `src` подходящего типа в области видимости: элементы `Name: src.Name,` с хвостом
   « map» и «Map all remaining fields from src» (вставляет все уверенные поля в порядке объявления); на строке после
   `dst.Name = src.Name` — элементы-присваивания. Поля неподходящего типа и уже заданные не предлагаются.
4. **Память принятий**. Выбрать один и тот же элемент 3 раза в похожем контексте — он поднимается в списке (в обычной сборке —
   внутри своей группы приоритета, в ML-сборке — бонус к скору ранкера). Reset Memory обнуляет. Хранится в кэше IDE проекта,
   не в `.idea`.
5. **Выбор импорта**. В файле с `import "time"` напечатать `rand.` — квик-фикс «Import …» и список предлагают `math/rand` первым;
   с `import "crypto/sha256"` — `crypto/rand`. `template` → `text/template`, при `net/http` в импортах — `html/template`.
   Список дополнения теперь показывает все одноимённые пакеты (раньше второй терялся как дубликат).

## Если что-то не так
- Серого текста нет совсем: строка состояния на странице Smart Completion — модель не загрузилась (нет файлов в `ml/go/` jar или
  в каталоге моделей) или ядра не загрузились (тогда scalar, медленнее, но работает).
- Подсказки странные внутри строк — выключить «Suggest inside string literals».
- Ранкер молчит: схема признаков `rank.cml` должна совпадать с `GoMlFeatures` (ошибка в логе «trained for another feature set»).

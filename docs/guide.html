Подсказки

Список собирается из ответа gopls и из того, что плагин знает сам. Возможности из этого раздела отключаются по отдельности в настройках.

ЧтоПримерПояснение
Импорт при выбореstrings.ToUp даёт ToUpperПакет подключается сам.
Функции и типы по имени новоеPrintl даёт fmt.PrintlnСтандартная библиотека, прямые зависимости и пакеты проекта. Работает без gopls.
Пакеты по имени новоеhtt даёт httpИмпорт добавляется при выборе.
Значения return новоеreturn ni даёт nil, errВсе значения функции одним пунктом.
Подходящее по типу новоеЖирным в спискеВ аргументе вызова, в return, в var x T =.
Порядок списка новоеni: сначала nilИмена, начинающиеся с набранного, стоят выше остальных.
Аргументы вызова новоеСписок после ( и после , Открывается сам, вместе с подсказкой о параметрах.
Скобки после типа новоеc := http.Client{}Там, где ожидается значение. Курсор встаёт между скобками.
Тип из JSON новоеty даёт type from JSON...Структуры с тегами json по документу из буфера обмена или из диалога: вложенные объекты — свои типы, массивы — срезы, даты RFC 3339 — time.Time с импортом. Есть и в Alt+Insert.
Недостающие методы интерфейса новоеfu даёт func (o *Order) Total() int {...}Для типа файла, у которого есть часть методов интерфейса проекта, но не все.
Константы HTTP новоеWriteHeader(40 даёт http.StatusNotFoundЧисло там, где ждут статус: WriteHeader, http.Error, сравнение с StatusCode, c.JSON(, case. Импорт net/http добавляется.
Раскладка времени новоеtime.Parse("20 даёт 2006-01-02Внутри строки time.Parse / t.Format: целые раскладки (RFC 3339, дата, время, 02.01.2006) и их части с подписью — Jan месяц, 15 час, Z07:00 смещение.
Заготовки по ключевому слову новоеty даёт type Name struct {...}В начале строки. Наверху файла: type, func (и метод для каждого типа файла), var, const, import, в _test.go — Test, табличный тест, Benchmark, Fuzz. В теле: for по срезам, картам и каналам, объявленным выше, if err != nil, comma-ok, switch, select, go, defer, chan, map; в тесте — t.Run, t.Parallel, t.Cleanup. Tab переводит по местам для ввода. Работает без gopls.
Регистр букв новоеclient даёт http.ClientДля пунктов плагина не учитывается. Для пунктов gopls действует настройка IDE Match case.
Русская раскладка новоеаьею печатается как fmt.В коде. В строках и комментариях текст остаётся русским.
Теги структурыВнутри обратных кавычекКлючи, имя поля в разных стилях, опции ключа.
Файл go.modДирективы, пути, версииПути берутся из кэша модулей, версии также у прокси модулей.

Действия

Список по Alt+Enter показывает то, что применимо в месте курсора.

Alt+Enter

ПунктГде доступенЧто делает
Handle errorВызов отдельной строкойОборачивает вызов в проверку ошибки.
Add if err != nil checkПосле присваивания ошибкиДобавляет проверку с return.
Add missing returnФункция с результатом без returnДобавляет return с нулевыми значениями.

Add struct tags…Структура или её полеДиалог: ключи, стиль имён, omitempty.
Reorder fields for a smaller struct новоеСтруктура, которую компилятор выравнивает с лишними пробеламиПоля в порядке, дающем наименьший размер (сначала самые выровненные и крупные), в тексте пункта — размер до и после; комментарии остаются при своих полях. Размеры считаются по тексту: базовые типы, указатели, срезы, map, chan, func, известные типы stdlib (time.Time, sync.Mutex…) и типы этого файла; с неизвестным типом пункт не появляется. То же — исправление к находке fieldalignment линтера (govet). Позиционные литералы структуры править вручную.
Implement interface…ТипПопап с поиском по интерфейсам проекта и, с галочкой Non-project, стандартной библиотеки и зависимостей; дописывает недостающие методы. Тот же попап — Ctrl+I.
Generate testФункция или методТабличный тест в файле _test.go.
Fill all fields новоеЛитерал структуры или имя типаЗаполняет поля нулевыми значениями и добавляет импорты. На имени типа без скобок сначала дописывает {}.
Optimize imports новоеСтроки импортовУбирает неиспользуемые, добавляет недостающие, сортирует.
Действия gopls новоеКурсор или выделениеExtract variable, Extract function, Inline call, Invert if, Add test и другие, под своими именами. Извлечение доступно при выделении.
Refactorings and actions of gopls…Любое местоТе же действия отдельным списком. Стоит внизу.
Исправления линтераЗамечание golangci-lintHandle error, Ignore error explicitly, Suppress with //nolint.
Исправления goplsОшибка или предупреждениеИсправления, которые сервер языка предлагает к своим замечаниям.

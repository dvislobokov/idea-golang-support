# Каталог проверок Go для Go Project Support

> Рабочий черновик от 2026-10-02. Разделы security, govet, go-critic, modernize и архитектура ещё дополняются. Сборка и тесты не запускались.

Источники: ресурсы установленного GoLand 2026.2.3 (build 262.10968.67) и закреплённые исходники golangci-lint и анализаторов. Примеры ниже — иллюстративные фрагменты: импорты, окружающие объявления и обработка не относящихся к правилу ошибок могут быть опущены. Исправление показывает направление изменения, а не обещание безопасного autofix.

## GoLand: 123 инспекции

### GoAssignmentToReceiver

**Условие:** Присваивание самому receiver меняет только локальную копию параметра.

Проблемный фрагмент:

```go
func (s *State) Reset() { s = &State{} }
```

Исправление / направление изменения:

```go
func (s *State) Reset() { *s = State{} }
```

**Оговорки:** Замена на запись через указатель допустима только при намерении изменить исходный объект; учитывать nil и mutex-поля.

### GoBoolExpressions

**Условие:** Часть булева выражения логически избыточна либо противоречива.

Проблемный фрагмент:

```go
if n > 10 && n > 5 { use(n) }
```

Исправление / направление изменения:

```go
if n > 10 { use(n) }
```

**Оговорки:** Нельзя удалять вызовы с побочными эффектами; учитывать NaN и короткое замыкание.

Исправление / направление изменения:

**Оговорки:** Сопоставлять старый и новый синтаксис логически; не выбрасывать ограничения других платформ.

### GoDeferGo

**Условие:** panic/recover вызываются непосредственно через go/defer с подозрительной семантикой.

Проблемный фрагмент:

```go

```

**Оговорки:** В примере recover вызывается непосредственно внутри deferred-функции; не скрывать panic без политики обработки.

### GoDfaErrorMayBeNotNil

```go

```

**Оговорки:** Нужны контракты результата/error; не все API возвращают невалидное значение вместе с ошибкой.

### GoDfaNilDereference

### GoIrregularIota

**Условие:** В iota-группе смешаны формы объявлений, вероятно меняющие ожидаемые значения.

Проблемный фрагмент:

### GoLeadingWhitespaceInDirectiveComment

**Условие:** Пробел отделяет // от директивы, поэтому она не распознаётся.

Проблемный фрагмент:

```go

```

Исправление / направление изменения:


**Оговорки:** Проверять, что это намеренная директива, а не её пример в документации.

### GoLoopClosure

**Условие:** Замыкание отложенно читает разделяемую переменную цикла.

Проблемный фрагмент:

```go

```

Исправление / направление изменения:


**Оговорки:** Пример опасен для старой семантики до Go 1.22; при := в новых версиях не предупреждать по старому правилу.

### GoMaybeNil

**Оговорки:** Нужны summaries вызовов, контекст ветвей, рекурсивные SCC и объясняемый путь.

### GoMissingTrailingComma

**Оговорки:** Диагностика синтаксиса; не каскадировать ошибки по всему файлу после одной запятой.

### GoRedundantComma

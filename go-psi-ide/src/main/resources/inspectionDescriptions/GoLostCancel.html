Reports the cancel function returned by context.WithCancel, WithTimeout, WithDeadline or their Cause variants when it is discarded, or when some path from the assignment reaches a return without calling, deferring, passing or storing it: the context leaks until its parent is cancelled (vet lostcancel). 
ctx, cancel := context.WithTimeout(ctx, time.Second)
if err := check(); err != nil {
    return err // cancel is not called on this path
}
defer cancel()
Paths that end in a panic or os.Exit do not count.

Reports a comparison whose result the data flow knows, so the condition is always true or always false:
  • a nil comparison of a variable whose nil-ness is known on every path: after if x == nil { return }, after &T{}, new, make or a literal, after x = nil;
  • a comparison of a local variable every reaching assignment of which stores the same literal, with a literal or another such variable;
  • a comparison of literals.
n := 0
if n == 0 { // Condition 'n == 0' is always 'true'
}

Named constants never make a condition constant here: if debug or runtime.GOOS == "linux" is configuration that build tags change. Variables whose address is taken or that a closure captures are not tracked.

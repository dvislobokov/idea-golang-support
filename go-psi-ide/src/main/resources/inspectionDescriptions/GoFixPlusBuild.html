Reports // +build lines of the file header (Go 1.17 reads //go:build; needs go 1.17 in go.mod). With a //go:build line the old lines are no longer needed and Remove obsolete +build lines deletes them; without one, Replace +build lines with //go:build writes the equivalent expression (several lines are ANDed). 
//go:build linux && amd64
// +build linux,amd64

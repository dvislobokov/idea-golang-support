Reports misuse of the errors package:
  • the second argument of errors.As is not a non-nil pointer to a type that implements error or to an interface type, or is a *error (vet errorsas). Quick fix: Take the address of target;
  • err == ErrX or err != ErrX with a package-level error variable: the comparison is false once the error is wrapped (weak warning). Comparisons with nil and comparisons inside Is methods are not reported. Quick fix: Replace with errors.Is(err, ErrX).

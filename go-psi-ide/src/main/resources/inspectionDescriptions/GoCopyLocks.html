Reports a value that contains a lock being copied (vet copylocks): a sync.Mutex, RWMutex, WaitGroup, Once, Cond, Map, Pool, a sync/atomic type, or any type with pointer methods Lock and Unlock, also inside struct fields and arrays. Reported: parameters and receivers declared by value, call arguments, returns, assignments from an existing value, and the value variable of range. Quick fix for a receiver: Use a pointer receiver.

Reports the copy v := v of a range variable in the loop body. Since Go 1.22 every iteration has its own loop variables, so the copy is not needed.

Before:

for _, v := range values {
    v := v
    go use(v)
}

After the quick fix Remove the redundant copy:

for _, v := range values {
    go use(v)
}

Reported only when the go version of the module (or the //go:build go1.N line of the file) is at least 1.22.

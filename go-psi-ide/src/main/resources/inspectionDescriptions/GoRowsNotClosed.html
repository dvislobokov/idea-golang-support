Reports rows, err := db.Query(…) (QueryContext too, on *sql.DB, *sql.Tx, *sql.Conn and *sql.Stmt) when some path on which err is nil reaches a return without rows.Close(), called or deferred: the connection stays busy (linter sqlclosecheck). Also reports a for rows.Next() loop when rows.Err() is never called: an error that ended the iteration is lost (linter rowserrcheck). 
rows, err := db.QueryContext(ctx, query)
if err != nil {
    return err
}
defer rows.Close()
for rows.Next() {
    …
}
return rows.Err()
Not reported when rows is returned, passed to a function, stored or captured by a closure. The quick fix adds defer rows.Close() after the error check.

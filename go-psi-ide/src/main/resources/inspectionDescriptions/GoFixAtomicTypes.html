Reports a variable of type int32, int64, uint32 or uint64 without an initial value whose every use is &n passed to the matching sync/atomic function (AddInt64, LoadInt64, StoreInt64, SwapInt64, CompareAndSwapInt64): the typed wrappers of Go 1.19 make a non-atomic access impossible. Locals and unexported package-level variables used only in their file; struct fields are not reported. 
var hits int64
atomic.AddInt64(&hits, 1)
// var hits atomic.Int64; hits.Add(1)

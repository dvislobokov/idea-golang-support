Reports a send ch <- v or a second close(ch) that some path reaches after close(ch) in the same function, with ch not reassigned in between: both panic at run time. 
close(results)
results <- last // panic: send on closed channel
Only the paths within one pass of the function are followed: the next iteration of a loop, which a closed flag usually guards, is not considered. Channels assigned inside a closure or whose address is taken are not checked.

Reports context.Background() or context.TODO() passed as an argument while a parameter or local variable of type context.Context is in scope: the callee loses the caller's cancellation and deadline (linter contextcheck). 
func (s *Server) Load(ctx context.Context, id string) error {
    return s.db.Get(context.Background(), id) // use ctx
}
Not reported in main, init, test files, goroutine literals and deferred calls, where detaching from the caller's context is usually deliberate. The quick fix passes the variable instead.

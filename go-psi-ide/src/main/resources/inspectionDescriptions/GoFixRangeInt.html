Reports a counted loop for i := 0; i < n; i++ that can range over the integer: the loop variable is not changed in the body, and the limit is an int that the body does not change. An unused index becomes for range n.

Before:

for i := 0; i < n; i++ {
    ch <- i
}

After the quick fix Replace with range over int:

for i := range n {
    ch <- i
}

Reported only when the go version of the module (or the //go:build go1.N line of the file) is at least 1.22.

Reports a for range loop that searches a slice for a value: return true / return false becomes slices.Contains, return i / return -1 becomes slices.Index, and if v == x { ...; break } becomes if slices.Contains(s, x) { ... }.

Before:

for _, v := range names {
    if v == name {
        return true
    }
}
return false

After the quick fix Replace loop by call to slices.Contains:

return slices.Contains(names, name)

Reported only when the go version of the module (or the //go:build go1.N line of the file) is at least 1.21.

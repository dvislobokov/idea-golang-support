Checks build constraint comments (vet buildtag):
  • a //go:build expression with a syntax error (error);
  • a //go:build line after the package clause or not followed by a blank line, and a second //go:build line;
  • a // +build line in a file without //go:build (weak warning). Quick fix: Add //go:build line with the equivalent expression;
  • a tag one edit away from a known GOOS or GOARCH, such as linx (weak warning). Custom tags are not reported. Quick fix: Replace with 'linux'.

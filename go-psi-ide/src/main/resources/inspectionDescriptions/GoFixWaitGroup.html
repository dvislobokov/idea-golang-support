Reports wg.Add(1) right before go func() { defer wg.Done(); ... }() (or with wg.Done() as the last statement) on a sync.WaitGroup: Go 1.25 does this with wg.Go (modernize waitgroup; needs go 1.25 in go.mod). 
wg.Add(1)
go func() {
    defer wg.Done()
    work()
}()

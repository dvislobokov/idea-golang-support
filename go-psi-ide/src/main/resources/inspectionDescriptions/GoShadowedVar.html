Reports a local variable that shadows a variable, constant, parameter, result or receiver of an enclosing scope, or a package-level variable or constant of the same package. The name is painted with the Shadowing variable colour. A := that reuses a variable of its own scope does not declare one and is not reported; nor are parameters, x := x and switch x := x.(type). 
value, err := load(name)
if value != "" {
    value, err := load(value + "x") // shadows both
    ...
}

Quick fixes: Navigate to shadowed declaration, Rename variable.

Reports strings.HasPrefix followed by strings.TrimPrefix with the same arguments (also the Suffix pair and package bytes): strings.CutPrefix checks and trims at once.

Before:

if strings.HasPrefix(s, "go") {
    rest := strings.TrimPrefix(s, "go")
    ...
}

After the quick fix Replace HasPrefix + TrimPrefix with CutPrefix:

if after, ok := strings.CutPrefix(s, "go"); ok {
    rest := after
    ...
}

Reported only when the go version of the module (or the //go:build go1.N line of the file) is at least 1.20.

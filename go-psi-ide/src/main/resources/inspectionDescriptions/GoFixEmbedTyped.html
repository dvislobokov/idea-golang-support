Reports an unexported //go:embed variable that is converted at every use: a string used only as []byte(x), or a []byte used only as string(x). Embedding with the wanted type avoids a copy per use. Only conversions passed directly as call arguments are counted, and only when no other file of the package mentions the name. 
//go:embed schema.json
var schema string

json.Unmarshal([]byte(schema), &v) // declare schema as []byte

Quick fix: Declare 'x' as []byte (or string) changes the type and removes the conversions.

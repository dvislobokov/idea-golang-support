Reports strings.Index (or bytes.Index) whose result is only checked for a match and used to slice the text before and after the separator: strings.Cut returns both parts.

Before:

i := strings.Index(s, "=")
if i >= 0 {
    key, value := s[:i], s[i+1:]
    ...
}

After the quick fix Replace strings.Index with strings.Cut:

before, after, ok := strings.Cut(s, "=")
if ok {
    key, value := before, after
    ...
}

Reported only when the go version of the module (or the //go:build go1.N line of the file) is at least 1.18.

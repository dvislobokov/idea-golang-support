Reports a named parameter of a function or method declaration that its body never uses (gopls unusedparams).

To avoid false positives the check stays quiet where the signature is dictated from outside: functions without a body, with an empty body or a body that only panics; init and main; test, benchmark, fuzz and example functions; functions marked //export or //go:linkname; HTTP handlers (http.ResponseWriter, *http.Request); exported functions and methods (callers in other modules fix the signature); parameters of type *testing.T, *testing.B, *testing.F, testing.TB; methods that implement an interface method; functions used as values anywhere in the project (passed as a callback, assigned). Function literals and parameters named _ are never reported.

Quick fixes:

  • Rename to _ keeps the signature.
  • Remove unused parameter removes it from the signature and the matching argument from every call in the project (imports left unused by the removal are dropped). It is offered only when every reference to the function is a direct call whose argument at that position has no side effects (no calls, no receives) and no call is a method expression T.M(recv, …).

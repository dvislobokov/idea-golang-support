Reports resp, err := http.Get(…) (also Post, Head, PostForm and the same methods of *http.Client, Do included) when some path on which err is nil reaches a return without resp.Body.Close(), called or deferred: the connection is not reused and leaks (linter bodyclose). 
resp, err := http.Get(url)
if err != nil {
    return err
}
if resp.StatusCode != http.StatusOK {
    return fmt.Errorf("status %d", resp.StatusCode) // the body is not closed on this path
}
defer resp.Body.Close()
Not reported when resp is returned, passed to a function, stored or captured by a closure; a path that passes resp.Body to a call counts as handled. The quick fix adds defer resp.Body.Close() after the error check.

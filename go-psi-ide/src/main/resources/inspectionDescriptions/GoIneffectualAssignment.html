Reports a value assigned to a local variable that no path reads afterwards (like ineffassign). 
n := len(a)
n = len(b) // the first value is never read
return n
Not reported: _, variables captured by a closure or whose address is taken, parameters, named results read by a bare return, zero-value initializations (var x T, x := 0, x = nil), values only followed by a panic, and error values reported by Error overwritten before it is checked. Quick fix: Remove assignment for an =, op= or ++ statement whose right side has no calls.

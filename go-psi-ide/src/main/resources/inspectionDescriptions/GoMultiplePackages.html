Reports files of one directory that declare different packages (the go command's found packages a (a.go) and b (b.go) in <dir>).

As in go/build: the files that match the build context, test files included, are taken in name order; the first one names the package, and every later file with another package clause is reported. An external test package (package a_test in a _test.go file) belongs to package a; files excluded by build constraints and package documentation do not count.

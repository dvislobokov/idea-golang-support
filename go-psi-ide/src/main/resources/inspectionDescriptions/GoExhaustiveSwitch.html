Reports a switch that does not name every member of its type and has no default case (the rules of the exhaustive analyzer):
  • an expression switch over an enum: a named type with constants of that type in its package. Constants with equal values are one member; unexported constants of another package are not members; bit-flag enums (1 << iota) are skipped;
  • a type switch over an interface of the project: every type of the project that implements it. A case naming an interface covers its implementations. Interfaces of libraries and the standard library are skipped.

The option reports switches with a default case as well. The quick fix Add missing cases inserts the cases before default, like the Fill switch intention.

switch c { // Missing cases in switch of type Color: Blue
case Red, Green:
}

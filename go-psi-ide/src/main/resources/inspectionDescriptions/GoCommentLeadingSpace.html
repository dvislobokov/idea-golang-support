Reports a line comment whose text starts right after //. Directives (//go:generate, //nolint, //lint:ignore, //line, //export, cgo //# lines, //+build) are not comments for this check.

The inspection works only when Add a leading space to comments is selected in Settings | Editor | Code Style | Go, tab Other (off by default).

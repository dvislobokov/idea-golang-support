Reports irregular usage of iota within a constant declaration: two constant specifications with a textually identical expression list containing iota, with only specifications without an expression list (at least one) between them. The implicit repetition already gives the later specification that value, so the repeated list reads as if it restarted or changed something. 
const (
    a = iota // 0
    b        // 1
    c = iota // 2: the expression is redundant
)
Adjacent repeats (A0 = iota right after A1 = iota) and lists that differ (iota + 40, iota) are not reported.

Quick fixes: Remove the repeated expression.

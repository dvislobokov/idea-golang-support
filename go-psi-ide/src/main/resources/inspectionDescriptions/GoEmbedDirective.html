Checks //go:embed comments for what makes go build fail:
  • a pattern that matches no file (pattern x: no matching files found) or a directory without embeddable files;
  • an invalid pattern: an empty element, . or .., a leading or trailing /, a backslash, a malformed [class];
  • a directive that is not directly above a package-level var (blank lines and other comments may stand between);
  • a file that does not import "embed". Quick fix: Add import "embed" — a blank import when only string / []byte variables are embedded, a plain one for embed.FS.

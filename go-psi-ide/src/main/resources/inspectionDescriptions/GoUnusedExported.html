Reports an exported package-level function, type, variable or constant that nothing in the project refers to.

An exported name of a library may be used by modules outside the project, so only packages whose every importer is project code are checked: packages under an internal/ path element, and packages of a project module that has a package main (an application). Methods (interfaces call them implicitly), package main, _test.go files, Test/Benchmark/Example/Fuzz functions and functions marked //export or //go:linkname are skipped. A use in a test file counts. Uses through reflection, //go:linkname from another package or code generation are not seen.

Off by default: it runs a project-wide reference search for every exported name of the file.

Reports missing or malformed doc comments of exported package-level declarations (golint / revive exported; off by default):
  • an exported function, method (of an exported type), type, const or var without a doc comment. A comment on a const (...) / var (...) group counts for all its specs. Quick fix: Add doc comment (inserts // Name above the declaration and puts the caret after it);
  • a doc comment that does not start with the declared name (A Name, An Name and The Name are accepted, Deprecated: paragraphs are ignored). Quick fix: Start comment with 'Name'.
_test.go files, main packages and generated files (// Code generated ... DO NOT EDIT.) are skipped.

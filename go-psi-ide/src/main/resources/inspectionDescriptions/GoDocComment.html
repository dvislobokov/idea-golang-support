Reports missing doc comments of exported package-level declarations (golint / revive exported; off by default):
  • an exported function, method (of an exported type), type, const or var without a doc comment. A comment on a const (...) / var (...) group counts for all its specs. Quick fix: Add doc comment (inserts // Name above the declaration and puts the caret after it).
A comment that does not start with the declared name is reported by Comment of exported element starts with the incorrect name. _test.go files, main packages and generated files (// Code generated ... DO NOT EDIT.) are skipped.

Reports a loop over a map that only copies it into another map (maps.Copy) or appends its keys or values to a slice (slices.AppendSeq, or slices.Collect right after var keys []K, over maps.Keys / maps.Values).

Before:

for k, v := range src {
    dst[k] = v
}
var keys []string
for k := range m {
    keys = append(keys, k)
}

After the quick fix Replace loop with maps.Copy:

maps.Copy(dst, src)
keys := slices.Collect(maps.Keys(m))

Reported only when the go version of the module (or the //go:build go1.N line of the file) is at least 1.21 (1.23 for keys and values).

Reports package-level variables whose initialization depends on themselves through declarations in other files of the package (the compiler's initialization cycle for x, followed by ; x refers to f parts).

Cycles inside one file are reported by the compiler checks; this inspection only reports the cycles that go through another file, once, at the cycle's first variable in package order. Function bodies and initializers of other files are read when the walk reaches them, so packages of more than 100 files are skipped.

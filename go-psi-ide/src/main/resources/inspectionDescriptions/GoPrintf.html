Reports calls of printf-like functions whose format does not match the arguments, as go vet's printf check does: a verb that does not fit the argument's type (%d of a string, %s of an int without a String method), too few or too many arguments (%[n]d indexes and * width and precision are counted), unknown verbs and flags, %w outside fmt.Errorf or with an argument that is not an error, a Printf directive in a Println argument and a redundant newline at the end of a Println.

Checked: fmt, log, *log.Logger, testing.T/B/F/TB, and the functions and methods of the same package whose last parameters are (format string, args ...any) and that pass both on to a printf-like function. Formats that are not constant are skipped.

Quick fixes replace the verb with the one the argument's type takes, remove the extra arguments or add %v placeholders for them. In fmt.Errorf, %v of an error offers %w.

Reports an address built as fmt.Sprintf("%s:%d", host, port), fmt.Sprintf("%s:%s", host, port) or host + ":" + port and passed to net.Dial, net.Listen, (*net.Dialer).DialContext and similar (directly, or through a local variable used only there): such an address does not work with IPv6 literals (modernize / vet hostport). 
conn, err := net.Dial("tcp", fmt.Sprintf("%s:%d", host, port))

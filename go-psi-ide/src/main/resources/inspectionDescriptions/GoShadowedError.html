Reports err declared with := in an inner block (not an if initializer) that shadows an outer err read after the block, when the inner value is only compared with nil: the error is not propagated and the outer value is returned. Quiet when the inner err is returned, wrapped or otherwise used. 
var err error
for _, p := range paths {
    data, err := os.ReadFile(p)
    if err != nil {
        continue
    }
    use(data)
}
return err

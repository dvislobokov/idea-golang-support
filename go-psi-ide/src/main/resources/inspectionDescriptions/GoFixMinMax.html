Reports a conditional assignment that picks the smaller or the larger of two values: it can use the built-in min or max. Only integers and strings (for floats the built-ins differ on NaN and negative zero) and operands without side effects.

Before:

if a < b {
    x = a
} else {
    x = b
}
if limit > maxLimit {
    limit = maxLimit
}

After the quick fix Replace with 'min':

x = min(a, b)
limit = min(limit, maxLimit)

Reported only when the go version of the module (or the //go:build go1.N line of the file) is at least 1.21.

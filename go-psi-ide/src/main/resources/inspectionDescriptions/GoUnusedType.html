Reports an unexported type (package-level or local) that nothing refers to. References inside the type's own methods, receivers included, do not count: without another use no value of the type can exist. 
type node struct{ next *node } // Unused type 'node'

Exported names are checked only where every importer is project code: a package under an internal/ directory or a package of an application module (one with a package main). Library API is never reported.

A reference counts as a use anywhere in the project except inside the declaration itself (recursion). Skipped: methods, init, main, blank names, Test* / Benchmark* / Example* / Fuzz* functions of test files, functions without a body or marked //export / //go:linkname, generated files.

Quick fix: Safe delete.

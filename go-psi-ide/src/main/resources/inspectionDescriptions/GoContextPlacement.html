Reports a context.Context that is out of place:
  • a context.Context parameter that is not the first parameter of a function or method (a testing *T, *B, *F or TB parameter may come before it);
  • a context parameter replaced (ctx = context.Background()) or shadowed (ctx := context.TODO()) inside its function: the caller's deadline and cancellation are lost;
  • context.Background() or context.TODO() passed as an argument where the function has a context parameter (weak warning).

Only the innermost function counts: a function literal without its own context parameter (a detached goroutine) is not reported. Quick fix: Use ctx.

Reports struct tags that are malformed or ambiguous (vet structtag):
  • a tag reflect.StructTag.Get cannot read: a value without quotes, a missing colon, an unbalanced quote, pairs not separated by spaces, suspicious spaces in json/xml values;
  • the same key twice in one tag (only the first is read);
  • two fields of one struct with the same json, xml, yaml or db name (- and empty names are skipped, XML attributes have their own names, embedded structs are not descended into);
  • a json or xml tag on an unexported field, which the encoders ignore.

Quick fixes: Fix quoting (json:name to json:"name") when the repair is unambiguous, Remove duplicate key.

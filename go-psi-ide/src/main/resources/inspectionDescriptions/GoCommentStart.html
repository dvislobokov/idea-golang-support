Reports a doc comment of an exported function, method, type, constant or variable that does not start with the declared name (A / An / The before it and a Deprecated: paragraph are accepted), and a comment that is nothing but the name. _test.go and generated files are skipped. The missing comment itself is reported by Missing or malformed doc comment (off by default).

Reports sort.Slice with the natural ascending order of an integer, float or string slice: slices.Sort does the same without the comparison function. The sort import is removed when nothing else uses it.

Before:

sort.Slice(s, func(i, j int) bool { return s[i] < s[j] })

After the quick fix Replace sort.Slice with slices.Sort:

slices.Sort(s)

Reported only when the go version of the module (or the //go:build go1.N line of the file) is at least 1.21.

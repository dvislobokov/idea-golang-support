Reports an error variable that receives the result of a call and, on some path, receives the result of another call before anything reads it: the first error is lost. 
_, err = w.Write(header)
_, err = w.Write(body) // the error of the first Write is lost
if err != nil {
Resets (err = nil) and wrapping (err = fmt.Errorf("...: %w", err), which reads the error first) do not count. Variables captured by a closure or whose address is taken are not checked.

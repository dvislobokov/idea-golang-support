Reports an import that closes a cycle among the packages of the project (the go command's import cycle not allowed). The message shows the shortest chain, for example import cycle: example.com/app/a → example.com/app/b → example.com/app/a.

The graph is built from the imports of non-test files (build constraints applied). An in-package _test.go file is compiled into its package, so its import is reported when the imported package leads back to it (import cycle not allowed in test); external test packages (package a_test) may import anything. Packages of the standard library, the module cache and vendor/ are not part of the graph.

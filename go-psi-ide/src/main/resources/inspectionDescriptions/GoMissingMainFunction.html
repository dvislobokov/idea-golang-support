Reports package main without func main (the linker's function main is undeclared in the main package).

All non-test files of the directory that match the build context (GOOS, GOARCH, build tags) are looked at; the problem is shown on the package clause of each of them. Test files and files excluded by build constraints are not reported. A main that is not a function is reported by the compiler checks (cannot declare main - must be func).

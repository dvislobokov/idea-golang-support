Checks the layout string of Time.Format, Time.AppendFormat, time.Parse and time.ParseInLocation (weak warnings; only string literals are checked):
  • a layout written in the notation of other languages, such as yyyy-MM-dd HH:mm:ss: Go layouts use the reference time Mon Jan 2 15:04:05 MST 2006. Quick fix: Convert to Go layout;
  • a layout with no time element at all: it is formatted to itself;
  • 2006-02-01, the ISO date with the day before the month. Quick fix: Swap to '2006-01-02'.

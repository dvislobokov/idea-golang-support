Reports a switch over a value of a named type that has no default case and does not handle every constant of that type declared in a const block that uses iota.

All constants of the block count, even those whose spec does not use iota itself. Constants with equal values are one member; unexported constants of another package are not members; bit flags (1 << iota) count too, as in GoLand. A switch with a default case is not reported.

const (
    a Weekday = iota
    b
    c Weekday = 5 // c is in the same const block even if it does not use iota
)

switch w { // Missing 'case' statements for 'iota' consts in 'switch'
case a:
}

Quick fixes: Create missing iota clauses adds one case b, c: clause with the missing constants; Create 'default' clause adds an empty default:. The Fill switch intention adds one case per constant, also for enums without iota and for type switches over interfaces of the project.

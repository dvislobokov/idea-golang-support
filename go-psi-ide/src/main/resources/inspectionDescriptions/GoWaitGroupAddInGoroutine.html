Reports wg.Add(…) of a sync.WaitGroup called inside the function literal of a go statement: the goroutine may start after wg.Wait() has already returned, so the wait does not cover it (vet waitgroup). 
go func() {
    wg.Add(1) // call it before the go statement
    defer wg.Done()
    work()
}()
Reported for an Add in the literal's own body, or deeper when the literal also calls wg.Done(); not reported when the literal also calls wg.Wait(). The quick fix moves the call before the go statement when its arguments do not use the literal's parameters or locals.

Reports language features newer than the Go version of the file: the go directive of its module, or a //go:build go1.N line of the file. Texts as the compiler's:
  • type parameter requires go1.18 or later
  • clear requires go1.21 or later, built-in min requires go1.21 or later, built-in max requires go1.21 or later
  • cannot range over n (variable of type int): requires go1.22 or later (range over an integer)
  • cannot range over seq (variable of type func(yield func(int) bool)): requires go1.23 or later (range over a function)
  • generic method requires go1.27 or later (a method with its own type parameters)
  • use of promoted field Bar.Baz in struct literal of type Foo requires go1.27 or later (a struct literal key reached through an embedded field)

As with the compiler, each text ends with (-lang was set to go1.17; check go.mod), or with (file declares //go:build go1.21) when the version comes from the file.

Nothing is reported when the version is unknown (no go.mod or no go directive).

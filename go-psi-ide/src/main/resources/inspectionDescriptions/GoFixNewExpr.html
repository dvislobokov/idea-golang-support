Reports pointers that Go 1.26 can create with new(expr) (modernize newexpr; needs go 1.26 in go.mod):
  • a call of a pointer helper such as func ptr[T any](x T) *T { return &x };
  • an immediately called literal func() *T { v := e; return &v }();
  • x := e right before p := &x (or p = &x, return &x) when x is used nowhere else.
timeout := ptr(30 * time.Second) // new(30 * time.Second)

An untyped constant passed to a non-generic helper keeps the helper's type: int64Ptr(5) becomes new(int64(5)).

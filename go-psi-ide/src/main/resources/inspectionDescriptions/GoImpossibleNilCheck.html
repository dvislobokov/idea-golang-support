Reports x == nil / x != nil where the nil-ness of x is known on every path: after &T{}, new, make, a literal or an earlier x != nil check, or after x = nil. The condition is always true or false. 
p := &T{}
if p == nil {
    return
}

Off by default: Constant condition (GoDfaConstantCondition) reports the same comparisons in GoLand's words.

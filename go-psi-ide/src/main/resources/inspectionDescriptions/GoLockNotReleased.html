Reports mu.Lock() or mu.RLock() of a sync.Mutex / sync.RWMutex (a local, a parameter, or a field path such as s.mu) when some path from it reaches a return or the end of the function without the matching Unlock() / RUnlock(), called or deferred: the next Lock deadlocks. 
s.mu.Lock()
if s.closed {
    return errClosed // still locked
}
s.mu.Unlock()
Not reported in functions whose name says they lock (lock…, …Lock, acquire…), when the function never unlocks that mutex (it is handed over on purpose), on paths that panic, pass the mutex to a call or return mu.Unlock.

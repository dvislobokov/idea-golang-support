Reports a loop over the indices of a slice from the last one down to zero: it can range over slices.Backward. Reads of s[i] become the element variable.

Before:

for i := len(s) - 1; i >= 0; i-- {
    fmt.Println(s[i])
}

After the quick fix Replace with range over slices.Backward:

for _, v := range slices.Backward(s) {
    fmt.Println(v)
}

Reported only when the go version of the module (or the //go:build go1.N line of the file) is at least 1.23.

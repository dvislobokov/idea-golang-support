Reports an import of a package whose path has an internal element from a package outside the tree rooted at the parent of that element (the go command's use of internal package … not allowed).

a/b/internal/c may be imported by a/b and anything under it, not by a/x. The rule applies to project packages, to dependencies in the module cache (example.com/dep/internal/x from another module) and to the standard library (internal/abi, crypto/internal/…). The decision is the project model's, the same one that resolves the import.

Reports, in a Test, Benchmark or Fuzz function of a _test.go file, contexts the test can take from t.Context() (modernize testingcontext; needs go 1.24 in go.mod):
  • ctx, cancel := context.WithCancel(context.Background()) followed by defer cancel() becomes ctx := t.Context();
  • context.Background() / context.TODO() written directly in the test body becomes t.Context() (not inside function literals, and not in tests that register Cleanup: the test context is cancelled before cleanups run).

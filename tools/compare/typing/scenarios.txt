# Typing / keyboard scenarios: the plugin against GoLand (docs/compare/prometheus-typing-dumps).
# Format (one parser per side, same rules: tools/compare/typing/to_json.py and GoTypingHarnessTest.kt):
#   === ID | category | title         a scenario starts; a line starting with '#' at column 0 is a comment everywhere (sections too)
#   key: value                        header fields until the first section:
#       file:   main file name (default a.go); every file of a scenario lives in its own directory (one package)
#       steps:  yes = record the caret line and the selection after every key token
#       gofmt:  yes = to_json.py records what `gofmt` makes of the before-text (markers removed)
#       query:  declaration | implementations | super | usages | highlight | structure | paraminfo | quickdoc | exprtype | inlays | surround | generate
#               (run after the keys; the result is a list or a text instead of the edited file; surround and generate list the
#               popup items at the start state, before the keys, so that the keys can then apply one of them)
#       note:   free text for the reader (may repeat)
#   --- code            the main file; <caret>, <selection>...</selection> as in IntelliJ test data
#   --- extra NAME      another file of the same package (no markers)
#   --- paste           text {PASTE} puts on the clipboard: the lines joined with \n plus a final \n (whole lines copied)
#   --- paste inline    the same without the final \n
#   --- keys            literal text typed char by char through the typed handlers; lines are joined with nothing;
#                       tokens {NAME} / {NAME:arg}, NAME = [A-Z_]+ (a '{' not followed by that is a literal brace):
#                       {ENTER} {TAB} {BACKSPACE} {DELETE} {SPACE} {ESC} {LEFT} {RIGHT} {UP} {DOWN} {HOME} {END}
#                       {SAVE} (FileDocumentManager.saveAllDocuments: actions on save) {PASTE} (the paste section via the clipboard)
#                       {ACTION:id} (an action of the editor, e.g. EditorCompleteStatement, ReformatCode)
#                       {SURROUND:title} (Surround With item whose title equals title, else the first one starting with it)
# Section text: the lines up to the next '---' / '===' header, trailing blank lines dropped; code / extra end with one \n.
# Expected results are not written here: GoLand is the reference (tools/ui-robot/goland/analysis/typing_batch.js).

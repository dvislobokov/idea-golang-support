Reports a replace directive whose target is a local module directory (=> ../lib, => ./lib, an absolute path with a go.mod) in a module that has no go.work in its directory or above it. A Go workspace says the same without changing go.mod for a local checkout. The quick fix Create go.work writes go.work next to go.mod (go of the module, at least 1.18; use . and a use for every such directory) and removes those replace lines from go.mod. No go command is run.

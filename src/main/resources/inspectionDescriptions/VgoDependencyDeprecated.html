Reports a require of go.mod whose module is deprecated: the go.mod of its latest version carries a // Deprecated: comment, as go list -m -u module@latest answers. The message quotes the comment, which usually names the replacement module.

The check runs in the background together with the update check (Newer version of a dependency): when go.mod is opened and when its requires change, at most once an hour. It needs the network; turn this inspection off where the proxy must not be asked.

Reports an import of a package that govulncheck found vulnerable in the module version the project uses: Package 'x' of module m@v is affected by GO-YYYY-NNNN: summary. The quick fix Upgrade m to v runs go get m@v (the fixed version) in the background; for the standard library the message names the Go release with the fix. The results come from govulncheck -json ./..., run in the background when Settings | Tools | Go | Linters, Check for vulnerabilities with govulncheck is on (at project open, after go.mod / go.sum change, at most hourly otherwise), or by Go | Check Vulnerabilities. Nothing is reported before the first run.
